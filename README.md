# 🌡️ Weekly Temperature Tracker (Java)

This Java console application allows users to input and track daily average temperatures for a week (Monday through Sunday). It stores days and corresponding temperatures using two `ArrayList`s and provides a summary report with a calculated weekly average.

## 📋 Features

- Prompts user for each day of the week and its average temperature
- Accepts days in any order (Monday through Sunday)
- Prevents duplicate entries for the same day
- Validates day names and temperature inputs
- Displays all daily temperatures and the weekly average once the user types `"week"`

## 🧠 Technologies Used

- Java (Standard Edition)
- ArrayLists for dynamic data storage
- Loops and conditionals for control flow
- Scanner for user input
